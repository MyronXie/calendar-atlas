# 日历足迹 Calendar Atlas

把 ICS 日历整理成地图、时间轴、排行、旅行行程和年度回顾。

## 开始使用

- **Windows** 安装 Node.js 22 或更新版本。把 `calendar.ics`、`place.csv`、`config.json` 放进项目的 `atlas-data/`，双击 `日历足迹.cmd`，选 `1` 启动并打开浏览器，选 `2` 停止，选 `3` 查看状态。默认地址为 `http://127.0.0.1:8787/`。
- **手机** 打开已发布的网页并导入同一组文件。浏览器保存导入副本。 [打开网页版](https://myronxie.github.io/calendar-atlas/)
- **验证** 运行 `npm test`。测试和构建直接使用仓库中的依赖。合成数据和启动步骤见维护文档。
