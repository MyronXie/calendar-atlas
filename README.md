# 日历地图

日常操作请看 [使用说明.md](使用说明.md)。双击“启动足迹.cmd”即可启动并打开，双击“关闭足迹.cmd”停止本机服务。

双击“启动足迹.cmd”，访问 http://127.0.0.1:8787。需要本机 Node.js，无需安装依赖。日历、地点和配置集中放在项目根目录的 atlas-data 文件夹；备份整个文件夹即可。

## 当前数据文件

- atlas-data/calendar.ics：当前日历。应用只读，不修改事件。
- atlas-data/place.csv：地点库，地点管理直接读写。列为 location、address、adcode、lat、lon、firstShown、lastShown、valid、type、labels、aliases（另有可选 country、province、city、datum）。valid：YY/MM/DD=核验在营、no=停业、skip=待下次验证、空=未核验。
- atlas-data/config.json：合并存放黑名单（blacklist）和点位 emoji 映射（emojis）。
- atlas-data/.backups：页面保存地点或黑名单时自动生成的旧版本备份。

旧版升级时，首次启动会从 user-data 迁移这三个文件，旧目录保留作为备份。历史导出（旧 E 盘日历、outputs）不随工程保留，也不是默认活动数据源。环境变量 CALENDAR_PATH、PLACES_PATH 可显式覆盖活动源。不要直接把 atlas-data 文件夹放到公开网站。

## 手机端使用同一套数据

首次在新版 APK 中导入时，把 `atlas-data/` 里的 `calendar.ics`、`place.csv` 和 `config.json` 传到手机，在「导入/更新数据」中选择。以后只需传发生变化的文件，日历导出后直接替换原 ICS。GitHub Actions 仍构建不含私人数据的 APK。

## valid=no 的含义（已更正）

表示该地点现在已经停业，不是无效地址或黑名单。过去的事件、到访次数和同伴统计仍然保留；地点管理可选择“现已停业”查看。此类记录的现有坐标也继续可用。是否排除只能由独立黑名单决定。

此前 outputs 中把这 22 条记录导出为黑名单的快照语义有误，请不要再导入。活动黑名单位于 atlas-data/config.json 的 blacklist 字段，valid=no 不会自动生成黑名单。

## 黑名单与 emoji 配置

黑名单放在 atlas-data/config.json 的 blacklist 数组，每条规则的字段为 type、enabled、match_type、value、reason。无 source、start_date、end_date 列，规则不限时间。type 为 event 或 place；enabled 为 1/0；match_type 为 contains、exact 或事件专用 uid；value 为匹配值，reason 可留空。

排除设置与此文件直接同步，支持按类型筛选、搜索、新增、编辑、删除、启用复选框。操作成功即保存并刷新统计，每次写入备份到 .backups；外部修改造成版本冲突时拒绝覆盖，可重新读取。正在编辑规则时暂停自动刷新，保留表单。旧的分表不再读取，历史备份已清理。

valid=no 仍仅表示现已停业，与黑名单无关。

## emoji

具体地点到访一次时显示 emoji；多次仍显示次数；聚合群组继续显示数量。优先顺序：全部由 config.json 的 emojis 字段管理：placeEmojis 精确地点覆盖 > 事件规则 > labelEmojis 标签 > 其他关键词规则 > typeEmojis 分类 > defaultEmoji。

映射规则 scope 支持 event（事件名称）、place（地点名称）、type（地点分类），keywords 为任意匹配的词，emoji 为显示内容。当前包括演唱会/音乐会 🎵、寿司 🍣、火锅 🍲、烤肉 🥩、咖啡 ☕、面馆 🍜、披萨 🍕、博物馆 🏛️、公园 🌳、机场 ✈️、车站 🚆、酒店 🏨、桌游 🎮 等。映射只是展示提示，不参与地点识别、黑名单和统计。

## 地图与列表

具体地点层级提供旧工程 360、高德旧样式和 OSM 瓦片。省市国家层级使用本地行政边界，自动适配已到访区域。城市边界缺失时只显示点位。悬停提示横向显示。

地图下方时间轴支持年/月切换、点击柱子、拖动两端手柄和整体拖动选区；自适应宽度，无额外水平滚动条。关键词在事件列表上方。地点排行、同伴排行与事件行内点击共用筛选条件，条件以标签展示，可单独清除；地点和人物同时选中取交集。点击时间展开备注，点击事件名称筛选。地点、人物列可分别隐藏。

## 坐标与备注

未声明坐标系的大陆旧记录按 GCJ-02，境外按 WGS84；datum 单条声明优先，可为 gcj02、wgs84、bd09。百度来源用 bd09，原始 GPS 即使在国内也用 wgs84。源坐标不自动重写。

备注兼容旧空格分隔，同时支持中英文分号。人物仅从 Partner 当前行提取；Place/Places 和日期行程中的地点可提取。4月3日、Day2、第二天等标题，&、...、等几人等修饰词不计入人物/地点，原备注保留。

推荐新备注：
Partner：甲；乙
行程：4月3日 Day2
Places：地点一；地点二
安排：上午游览，另有几位朋友参加

## 隐私与验证

服务只绑定 127.0.0.1。日历、地址、人物、备注和 CSV 不上传；只有当前地图瓦片联网，地图服务仍可获知 IP 与视野区域。无遥测、在线地理编码或批量抓取。历史数据不会因为地点停业被删除。

node tests/runtime-test.mjs、node tests/marker-test.mjs、node tests/note-test.mjs、node tests/csv-test.mjs、node tests/data-config-test.mjs 用于本地验证。模块与交互测试采用模拟 DOM，不代表真实浏览器视觉验证。配置写入测试使用临时虚构文件，不修改真实黑名单。

## 可叠加的统一筛选

地图地点、行政区域、排行、事件行内的地点/人物，以及事件旁的 ⊕ 按钮，都写入同一个条件列表。重复点选同项取消；每个条件可点 × 删除；“清空筛选”删除所有条件与当前搜索草稿，保留时间范围、排除设置和显示偏好。

地点与人物条件各自均要求满足（多个人物表示共同参与）；多个事件名称取并集；事件类别与地点、人物、关键词之间取交集。地图行政区域条件表示该区域包含的地点集合中任一地点，不要求同一事件到访区域全部地点。

搜索范围可选全部、事件、地点、人物、备注。输入时实时预览；回车或“添加筛选”将当前关键词保存为条件并清空输入，以便继续叠加。多个关键词条件均需满足。事件名称仍只展开/收起备注，旁边的 ⊕ 专门用于按事件名称筛选。

## 周期事件开关

“按周期展开事件”开启时根据 RRULE/RDATE 计算当前范围内各次发生，遵守 EXDATE、单次例外与取消；关闭时只显示源事件的首次起止时间，首次时间不与筛选范围相交则不显示后续周期次数。这不是按名称去重，不同 UID 的同名事件仍分别统计。普通非周期事件不受开关影响。

## 紧凑显示、折叠与配色

黑名单列表每条一行：启用复选框、类型、关键词、匹配方式、编辑/删除图标；原因只在编辑窗口查看。地点管理每行显示名称、两位小数坐标（N/S/E/W）、停业标记与类型标签；坐标系、地址等详细信息保留在设置窗口中。地点排行不显示坐标状态，齿轮按钮打开设置。

地图单次 emoji 改为深色底；底图名称简化为 360、高德、OpenStreetMap。标题改为“时间足迹”，移除标题旁重复日期范围，时间轴两侧范围仍保留。时间足迹和事件区域标题放大。

地图、时间足迹、事件各自可点击标题收起/展开，左侧“外观”也有对应开关。配色可选苔绿、雾蓝、紫藤、琥珀、岩灰，作用于控件、选中状态、时间轴、点位和行政地图；真实瓦片保持提供方原样。配色和折叠偏好保存在当前浏览器，数据文件不改写。appearance-test.mjs 与 runtime-test.mjs 覆盖格式、配色切换和独立折叠；不是浏览器视觉检查。

## 左右抽屉、比例时间柱与紧凑窗口

顶部标题栏只保留“排行”和“设置”入口。左抽屉仅有地点/同伴排行；地点管理、排除设置、显示偏好统一位于点击后弹出的右侧设置抽屉。地图的底图、层级、热力图等控件，以及事件地点/人物列勾选都移到右侧“偏好”。清空筛选与搜索范围、关键词框、添加筛选在同一行。右侧抽屉可通过关闭按钮、遮罩或 Esc 关闭。

地图、时间足迹、事件标题统一 19px，其余主要正文提高一级；时间轴操作说明保持 11px 并置于标题旁。窗口较窄或较矮时，地图预留高度进一步缩小。

时间轴底柱为应用黑名单后的周期事件量（未应用关键词或实体筛选）；高亮段为当前所有筛选和排除规则后的事件量。按事件开始年月分组，年视图显示“筛选数/原始数”，月视图仅显示高亮比例，悬停均有数量及百分比。日期范围之外的高亮为零（跨日事件按其原始开始期归属）。同一范围下周期展开开关对分子、分母一致。

非零底柱最少 7px，非零高亮最少 4px，且不超过底柱高度；筛选数等于原始数时填满底柱。极小数量的可见高度不严格按比例，以真实数字和提示比例为准。

## 时间颜色和组别筛选更新

黑名单排除属于基础数据清理，排除后的事件才进入时间底柱。没有关键词、组别、事件、地点、人物等普通筛选时，不绘制对比色覆盖层；年柱显示原始数量。时间选中范围用正常深色，未选中用浅色，月份仍以同色深浅交替区分年份。普通筛选使用独立对比色覆盖层，年显示筛选/原始，月不显示数字。

比例显示采用 min(r^0.8, r+0.10) 的温和增强，极小数量保底高度也限制在该偏移范围内；0 保持 0，100% 填满。悬停数量和百分比均为真实值。

点击事件时间展开/收起原始备注；点击事件名称筛选，已移除 ⊕ 按钮。开头 [xxx]yyy 或【xxx】yyy 被解释为组别 xxx、事件名 yyy，点击时分别添加两枚条件，可单独删除。组别排行读取括号内名称，并按当前事件次数排名；同类型多个组别或事件名取并集，组别和事件之间取交集。源事件名称和备注不改写。
