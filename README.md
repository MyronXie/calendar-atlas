# 日历足迹 Calendar Atlas

把 ICS 日历里的事件、地点和同伴整理到地图、时间轴、排行、旅游行程和年度回顾。桌面端、手机网页版和 Android 都使用日历、地点与配置三份原文件。桌面端从 `atlas-data/` 读取，手机端从导入文件读取。

Windows 上安装 Node.js 22 或更新版本，在工程根目录的 `atlas-data/` 放入 `calendar.ics`、`place.csv` 和 `config.json`。双击 **启动足迹.cmd**，浏览器会打开 `http://127.0.0.1:8787/`。双击 **关闭足迹.cmd** 停止服务。桌面端无需安装 npm 依赖。

全新检出可直接运行 `npm test`。没有个人数据时，可用仓库内的样例启动桌面版或导入移动网页。[从零运行](维护与备份.md#从零开始验证)

## 项目目录

| 目录 | 用途 |
| --- | --- |
| `atlas-data/` | 私人日历、地点 CSV、配置及保存前备份 |
| `data/` | 全国和上海地图所用的公开几何数据 |
| `tools/` | 启动、停止、地点维护、照片地点提取和移动端构建 |
| `tests/` | 解析、筛选、地图、配置和 HTTP 回归验证 |
| `reports/` | 地点维护文档和本地报告 |
| `mobile/` | 生成的静态网页或 APK 构建输入 |
| `.github/workflows/` | Pages 与 APK 构建工作流 |

发布的网页版和 APK 使用不含私人文件的构建。手机端从本机导入原文件，桌面端的修改通过替换对应文件同步到手机。私人数据和生成的报告由 Git 忽略。
