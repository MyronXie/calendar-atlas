# 工程文件说明

当前仓库的代码按「网页根 / lib / server / tools / tests / data / vendor / docs」分层。`atlas-data/`、`mobile/`、`temps/` 为本地数据与生成物，不进 Git。

## 一、根目录（网页入口与配置）

| 文件 | 核心 | 全部功能 |
| --- | --- | --- |
| `index.html` | 单页应用骨架 | 排行抽屉与遮罩、工具栏、时间总览、地图卡片、事件列表与吸顶筛选、数据源区、地点编辑/黑名单/日历预览/行程/行程分享/年度回顾等对话框、SVG 图标库、加载 Leaflet 与 app.js |
| `app.js` | 前端主控（约 2500 行） | `startAtlas()` 启动绑定；`load()/refresh()` 装载与刷新；ICS 读取/替换/预览；时间轴与统计（年/月柱、拖选、聚焦频率、日期条件、计数布局）；筛选与排行；事件列表分批渲染；地图（地点/上海/全国/国家地区、聚合/热力图、标注、交互、重置）；设置抽屉（偏好/地点管理/排除设置）；地点与配置读写；行程与分享导出；年度回顾与 PNG 导出；主题/夜间；响应式与触控适配；版本展示 |
| `style.css` | 全局视觉与响应式 | 设计 token、主题 CSS 变量、抽屉/标签页、内容卡片、设置列表、事件操作、编辑对话框、地图覆盖样式、宽屏双栏与窄屏吸顶、夜间模式 |
| `package.json` | 项目元信息与脚本 | `type: module`；`start/test/audit/clean:calendar/sync/verify/apply/pending/build:mobile`；无外部依赖 |
| `.gitignore` | 忽略私人数据与生成物 | `atlas-data/`、迁移临时目录、`user-data/`、`mobile-data/`、`data/local-reference.json`、`temps/`、`mobile/`、`*.zip`、`*.bak`、`node_modules/`、`.env`、`*.key`、`*.keystore`、`*.jks` |
| `README.md` | 项目简介与文档索引 | 功能概述、启动方式、文档链接、目录表、发布说明 |
| `AGENTS.md` | 协作指南 | 接手步骤、从零运行、代码入口表、易回归行为、数据与交付约定 |
| `启动足迹.cmd` / `关闭足迹.cmd` | 双击启停桌面服务 | 调用 `tools/launch-app.ps1` / `tools/stop-app.ps1` |

## 二、`lib/`（浏览器与 Node 共用纯逻辑）

| 文件 | 核心 | 全部功能 |
| --- | --- | --- |
| `core.js` | ICS 解析与语义提取 | `parseCalendar` 解析/归并周期例外；`details` 提取标题、人物、地点、备注；`expand` 展开重复事件；`escape` 转义；`validCoord` 校验 |
| `calendar-import.js` | 新旧日历比对 | `compareCalendars` 输出新增/变更/缺失/未匹配地点 |
| `filters.js` | 筛选引擎 | 条件创建/切换、组别标题拆分、搜索范围判定、文本/日期/组合匹配、展示、排行隐藏 |
| `timeline.js` | 时间轴几何 | 年/月计数、命中比例与柱高、数字排布、日期分桶、频率分组、快捷时段、月列与区间 |
| `travel.js` | 行程逻辑 | 行程识别、日期/地点/详情、逐日遍历、到访计数、文件名 |
| `trip-share.js` | 行程分享图 | 截取地图、Canvas 绘制标题/日期/同伴/点位/连线/署名 |
| `annual-review.js` | 年度回顾绘制 | 全国/上海地图、区界与地铁、标注避让、整图导出 |
| `appearance.js` | 主题配色 | 8 套主题、日/夜色板、混色、主题解析、对比字色、坐标格式化 |
| `basemaps.js` | 在线底图 | 360/高德/OSM/OpenTopoMap 配置、瓦片来源汇总 |
| `emoji.js` | 图标选择 | 按地点覆盖→事件→标签→规则→类型→默认选择 emoji |
| `organize.js` | 黑名单应用 | `applyRules` 过滤事件与地点、`isPlaceExcluded`、`normalizePlace` 别名 |
| `geo.js` | 地理工具 | GCJ→WGS 转换、区域名缩写、多边形提取、点在多边形内 |
| `place-name.js` | 名称规范化 | `search/compact/loose` 三档与 `normalizePlace` |
| `place-categories.js` | 分类与索引 | 分类表、标签/别名拆分、地址推断区域、地点索引 |
| `data-formats.js` | CSV/配置解析 | `parseCSV/stringifyCSV`、黑名单校验、config v1/v2 解析、照片排除校验 |
| `city-boundary-data.mjs` | 城市边界拆分 | 按省级编码拆成城市索引与省级 FeatureCollection |

## 三、`server/`（桌面服务与文件 IO）

| 文件 | 核心 | 全部功能 |
| --- | --- | --- |
| `server.mjs` | 本地 HTTP 服务 | 安全头/CSP、Host/Origin 校验、静态白名单、`/api/health|meta|places|config|calendar`、城市边界接口、写队列与大小限制 |
| `atlas-data.mjs` | 路径助手 | `atlasFiles`、`atlasDataDirectory()` |
| `atomic-file.mjs` | 原子写 | `backupText` 备份、`atomicWrite` 临时文件+rename |
| `csv-store.mjs` | place.csv 读写 | `readPlaces`、`updatePlaces`（冲突 409、字段/坐标校验、备份、原子写）、转出 CSV 工具 |
| `config-store.mjs` | config.json 读写 | `encodeConfig` 输出 v2、`readConfig`、`saveConfig`（冲突、保留 emojis/photos、备份） |
| `calendar-store.mjs` | calendar.ics 替换 | `calendarVersion`、`replaceCalendar`（校验、冲突、备份、原子写） |
| `app-version.mjs` | 版本注入 | 读取 Git HEAD 提交并替换首页版本占位 |

## 四、`tools/`（离线运维与构建）

| 文件 | 核心 | 全部功能 |
| --- | --- | --- |
| `launch-app.ps1` / `stop-app.ps1` | 桌面服务启停 | 健康检查、端口占用、Node 定位、启动等待与打开浏览器；停止时校验进程归属 |
| `clean-calendar.mjs` + `清理日历.cmd` | 清理 Outlook HTML 冗余 | 删除 `X-ALT-DESC` 及续行、逐事件比对、`--write/--out`、默认预览 |
| `outlook-plaintext.ps1` + `Outlook正文转纯文本.cmd` | Outlook 正文转纯文本 | RTF/ALT 体积筛候选、默认预览、`-Apply` 写回、UI 自动化 |
| `audit-calendar.mjs` | 日历体检 | 标题/时间/组别/备注检查、人物地点歧义、重复 UID、写法候选、缺坐标清单；输出到 `temps/` |
| `place-common.mjs` | 地点流程公共库 | 归一/相似/距离、高德 text/around/逆地理、百度检索、Photon 境外、CSV 读写、日期工具 |
| `place-sync.mjs` | 日历→地点同步（只读） | 提取地点词条、按 config 黑名单过滤、直接/新增/改名/未匹配分类、MD 与决策 CSV |
| `place-verify.mjs` | 地点有效性核验（只读） | 跳过停业与近期、境内/境外核验、存在/改名/停业/待人工、报告与决策 CSV |
| `place-apply.mjs` | 决策写回 | `sync`/`verify` 两种模式写回 place.csv 并备份 |
| `refresh-pending-places.mjs` | 待补坐标清单 | 过滤黑名单与已定位，输出待补 CSV |
| `photos-to-places.mjs` | 照片→行程报告 | EXIF/HEIC 扫描、聚类、排除日常区域、本地匹配、两级高德、境外 OSM、预算缓存、MD/CSV |
| `photo-exif.mjs` | EXIF/HEIC 读写 | JPEG/HEIC 解析与测试构造 |
| `build-mobile.mjs` | 移动包构建 | 复制源码/资源、拆分城市边界、`--data-less`、manifest、Service Worker、`serve.mjs` |
| `mobile-data-provider.js` | 手机数据层 | fetch 拦截、IndexedDB 导入、文件校验（构建为 `mobile/data-provider.js`） |
| `mobile-readonly.js` | SW 更新 | 注册 `sw.js`、安全重载（构建为 `mobile/mobile-readonly.js`） |

- 主题：`appearance-test.mjs`。
- 年度回顾：`annual-review-test.mjs`。
- 照片：`photo-cluster-test.mjs`。

## 六、`data/` 与 `vendor/`

- `data/china.json`：省级边界与中心点。
- `data/world.json`：世界国家边界（Natural Earth 10m）。
- `data/city-boundaries.json`：地级行政区边界。
- `data/shanghai-landmarks.json`：上海地铁/道路/区界/地标图层。
- `vendor/leaflet.js`、`leaflet.css`：地图引擎。
- `vendor/leaflet.markercluster.js`、`MarkerCluster*.css`：聚合插件。
- `vendor/leaflet-heat.js`：热力图。
- `vendor/ical.min.js`：ICAL.js。
- `vendor/gcoord.global.prod.js`（1.0.7）+ LICENSE：坐标转换。

## 七、`assets/` 与 CI

- `assets/icons/*.png`：favicon、apple-touch-icon、PWA 图标。
- `.github/workflows/deploy-pages.yml`：推 `main` 跑测试→构建 `--data-less`→检查无私人文件→部署 Pages。

## 八、`docs/`

- `使用说明.md`：启动、更新、筛选/地图/时间轴、行程、年度回顾、手机导入、备注格式、常见问题、config v2。
- `维护与备份.md`：从零验证、日常维护、Outlook 清理、Pages 发布、本地移动预览、ZIP 备份。
- `地点维护流程.md`：地点字段、名称匹配规则、同步/核验/决策表/写回。
- `配色清单.md`：主题色值、色阶用途、固定色、地铁线路色、对应代码。
- `工程文件说明.md`：本文件。

## 九、本地私密（不进 Git）

- `atlas-data/`：`calendar.ics`、`place.csv`、`config.json` 及 `.backups/`。
- `temps/`：临时报告、缓存、一次性脚本。
- `mobile/`：构建生成的静态包。
