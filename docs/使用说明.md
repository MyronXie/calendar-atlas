# 日历足迹使用说明

## 打开和关闭桌面版

双击 **启动足迹.cmd**。启动程序会检查本机服务，准备好后打开 `http://127.0.0.1:8787/`。也可在工程目录执行 `npm start`。需要 Node.js，桌面版无需执行 `npm install`。

关闭标签页后服务仍在运行。双击 **关闭足迹.cmd** 停止服务。修改服务端代码后先关闭再启动，修改页面代码后按 Ctrl+F5 刷新。

## 更新日历、地点和配置

桌面端和手机端使用同一套原文件。日常操作集中在项目根目录的 `atlas-data/`。

| 文件 | 操作 |
| --- | --- |
| `calendar.ics` | 从日历应用重新导出，保留文件名并替换原文件 |
| `place.csv` | 在 **设置 → 地点管理**编辑与保存，或用 UTF-8 CSV 工具合并 |
| `config.json` | 分三部分：`filters.blacklist`（黑名单，**设置 → 排除设置**保存）、`emojis`（图标映射）、`photos.exclusions`（照片日常区域）；结构带 `version: 2` |
| `.backups/` | 替换日历或保存地点、配置前生成的文件副本，可用于恢复 |

替换或外部编辑后，日历在 **设置 → 偏好**刷新，地点在 **地点管理**的 `place.csv` 标题旁刷新，配置在 **排除设置**的 `config.json` 标题旁刷新。地点和配置的文件时间与条数一起显示。桌面版启动时读取文件，外部修改后通过对应的刷新按钮读取。应用内保存后会自动更新页面和文件时间。遇到版本冲突时，先留存未保存的内容，再重新读取后提交。

在桌面端打开 **设置 → 偏好**，点击日历更新时间这一行的 **＋**。选择 ICS 后会显示新增事件、更新事件、当前文件中有而新文件中未包含的事件，以及地点库未匹配的名称。点 **仅在当前页面查看** 可以临时切换。点 **备份并替换本地日历** 会保存原文件副本并写入新日历。

从 Outlook 等客户端导出的 ICS 常带一份由 Word 生成的 HTML 正文（`X-ALT-DESC`），体积很大，且与纯文本 `DESCRIPTION` 内容重复。替换日历后，双击根目录的 **tools/清理日历.cmd**（或运行 `npm run clean:calendar -- --write`）即可清除这部分冗余：会先备份到 `.backups/`，清理后文件通常缩小约 30%，事件内容完全不变（命令会逐条比对，一旦不一致就中止）。注意这是**本地文件优化**，Outlook 每次重新导出都会再带回来，所以每次导出替换后跑一次即可，不影响 Outlook 本身。

季度地点核验、日历地点同步和待补坐标清单见 [地点维护流程](地点维护流程.md)。`valid=no` 表示地点现已停业，历史到访仍参加统计。需要排除时使用黑名单。CSV 的 `aliases` 保存别名，`labels` 用中文分号分隔标签，`datum` 指定坐标系，可填 `gcj02`、`wgs84` 或 `bd09`。

黑名单在 `config.json` 的 `blacklist` 数组中。规则包含 `type`、`enabled`、`match_type`、`value`、`reason`。`type` 可用 `event` 或 `place`，匹配方式可用 `contains`、`exact`，事件还支持 `uid`。地点 emoji 优先读取精确地点覆盖，再检查事件、标签、其他规则和分类映射，最后使用默认图标。

## 从照片提取地点行程

`tools/photos-to-places.mjs` 读取一个或多个文件夹里照片的 GPS 与拍摄时间，按日期整理出「某天什么时候去了哪些地方」的行程报告。脚本从本机文件解析 EXIF 或 HEIC 元信息，输出报告和 CSV。在线匹配发送地点簇的坐标，不上传照片。

```
# 先预览（只聚类、不调用高德，不消耗额度）
node tools/photos-to-places.mjs --dir "D:\照片\2024" --preview

# 确认后正式查询并生成报告（需要 AMAP_KEY）
$env:AMAP_KEY=...; node tools/photos-to-places.mjs --dir "D:\照片\2024" --dir "D:\照片\2025"
```

为避免高德额度浪费，流程是：

1. **先聚类**：大量连拍照片会先按空间范围（默认 100 米）聚成「地点簇」，可跨时间、跨文件夹，同一地点只查一次。
2. **排除日常区域**：在 `atlas-data/config.json` 的 `photos.exclusions` 保存矩形数组。每项包含数字字段 `latMin`、`latMax`、`lonMin`、`lonMax`，可选 `name` 用于说明。缺少时不排除。用 `--exclude-rect "latMin,latMax,lonMin,lonMax;..."` 可覆盖，传 `none` 可临时关闭排除。
3. **免费匹配优先**：先匹配 `place.csv`（**忽略 `valid=no` 的失效地点**，且排除住宿类，半径默认 60 米更精准）。命中即不再调用高德。
4. **两级查询未命中的簇**：一级用 `place/around`（风景名胜、科教文化、交通、购物）取「具体地点」，过滤停车场、公交站、几号楼、酒店/民宿、五金店/培训机构等；一级没有可用结果时，二级用 `geocode/regeo` 取「省/市/区」兜底。境外（港澳台及国外）改走免费 OSM/Photon。
5. **额度预算与缓存**：`--max-calls`（默认 400）限制本轮调用次数，按照片数从多到少消耗；查询结果缓存在 `temps/.photo-amap-cache.json`，重复运行或按邻近复用不再重复扣费。

常用参数：`--cluster-radius 100`（聚类半径米）、`--local-radius 60`（本地库匹配半径米）、`--dedupe 80`（同一天合并半径米）、`--fine-radius 800`（POI 搜索半径米）、`--max-calls 400`（调用预算）、`--preview`/`--no-amap`（跳过在线匹配）。报告输出到 `temps/照片地点记录_<日期>.md`，另含行程 CSV 与地点簇 CSV。若某轮额度不足，报告会把对应地点标为「未匹配地点/额度不足」，下次运行可继续。

## 地图、时间轴和筛选

工具栏的「排行」和「设置」可开关对应抽屉。窄屏打开抽屉后，遮罩锁住主页面，点遮罩不会关闭。可用抽屉右上角的关闭按钮，或在触屏上向外滑动。排行向左收起，设置向右收起。窄屏将「旅游行程」和「年度回顾」简写为「行程」和「回顾」。

- 地图入口包括地点、上海、全国和国家或地区。「重置」调整地图位置和缩放，保留当前筛选。「全国」右上角可切换按省份或按城市统计，并保留当前视野。按城市时可以开启「全部边界」或「高亮到访省份」。开启省份高亮后，省界与「全部边界」使用同样的淡化主色，到访城市使用主色填充和浅色描边。两个开关都开启时，到访省内的其他城市也使用浅色描边。
- 地点页可选择在线底图、热力图和聚合。切换底图会保留当前中心和缩放。单个地点用 emoji 表示，查看详情时显示到访次数。聚合圆标显示聚合的地点数。首次开启热力图时加载所需组件。
- 上海市以 20 km 比例尺打开，随主题改变底色。右上角可切换轨道交通、主要道路、区行政边界和主要地标。到 500 m 比例尺会显示道路和轨道线路名及车站圆点。触屏轻点或鼠标悬浮可查看站名。桥梁用实线，隧道用短虚线，区界用较疏的虚线。
- 双指缩放矢量地图时，文字与引线会暂时收起，松手后按新比例尺重新排布。
- 桌面悬浮地图点位查看详情，点击筛选。触屏轻点一次预览，再点同一位置或长按可筛选。点空白处可关闭预览。
- 启动时先显示事件列表，时间、地点和排行保持收起。点「时间」展开并计算全年统计，点「地点」展开地图并读取所需边界。时间标题显示起止日期，点击日期可修改范围，切换总览与聚焦会保留这个范围。应用聚焦日期条件后，标题日期旁会出现筛选图标，悬浮或触摸可查看条件。
- 总览可按年或按月显示。点击一根柱子选中该时段，横向拖过多根柱子选中连续时段。「最近」查看近一年，「全部」查看最早记录至今天或最后一条未来记录。
- 搜索框支持全部、事件、地点、人物、备注。输入即时预览，回车后可叠加条件。指定事件、地点或人物范围时，优先使用完整名称匹配，否则按部分名称匹配，列表高亮对应字段。事件标题旁的对比色筛选图标可悬浮或触摸查看生效的条件。点击事件名可按事件和组别筛选，点击事件时间会切到聚焦并选中该事件的日期范围。
- 聚焦日期和事件筛选共用搜索框下方的一行标签。标签较多时可横向滚动，点击标签可移除该项。输入关键词时事件结果即时预览，统计、排行和地图会在短暂停顿后刷新。搜索框旁的清空按钮只清除事件筛选。
- 点击地点、类型、同伴或组别的名称可筛选。点击左侧排名数字可把该项移到「不参与排名」，数字会变成隐藏图标，再点图标可恢复排名。条件标签的 × 删除单项，事件搜索区的清空按钮保留时间范围和聚焦日期条件。
- 不同类别的条件取交集，多个事件名称或组别取并集。
- 柱图优先显示总数和筛选命中数。日期条件数与任一项相同时省略，空间不足时也可省略。悬浮或长按提示仍提供完整计数。
- 聚焦可按年、月、周（星期几）、日（每月几号）和时（开始小时）叠加条件。同类多选取并集，不同类同时生效。月、周、日、时柱图下方可整组选中季度、工作日或双休日、旬，以及跨午夜的深夜等时段。全天事件没有开始小时，仍计入日期范围总数。
- 连续的聚焦日期条件可以合并为范围或季度、季节、工作日、双休日、旬和时段。聚焦的「当前」替换本组条件，「重置」清除全部日期条件。它们保留标题日期范围和关键词、地点等筛选。
- 两个模式的事件、天数、地点和同伴都按「筛选命中 / 日期条件 / 范围内总数」排序，前两项仅在对应条件生效时显示。柱图以主题主色表示标题范围内的事件。选择聚焦日期后，范围内事件改用中色，命中日期条件的部分用主色。对比色表示叠加其他筛选后的命中。柱图提示与统计使用相同的计数顺序，统计常驻在柱图下方。竖屏触控时可长按柱子查看提示，轻点和拖选仍用于选择。
- 双栏模式下，时间和地点在左栏，事件列表在右栏独立滚动。拖动中间分割条或在分割条上按 ←、→ 可以调整栏宽，两栏各保留至少 440 像素。从单栏切回双栏时恢复平分。时间标题栏按日期范围旁的剩余空间，先隐藏「最近／全部」或「当前／重置」的文字，再把「总览／聚焦」简写为「总／聚」，最后收窄时间单位按钮。必要时将控件移到下一行。单栏模式下，滚到事件时标题和筛选框会吸顶，向上滚动可回到时间和地点。
- 右栏或单栏事件列表变窄时，日期和时刻分两行显示，旁边依次显示事件、地点、人物和命中关键词的备注，每项各占一行。**地点** 和 **人物** 按钮控制各项显示。地点默认显示两行，命中的地点被折叠时自动展开，也可用箭头手动展开或收起。备注搜索和显示使用说明性文字，跳过 `Partner:` 和 `Place:` 行。
- 拖动时间或地点面板底部的横线可分别调整柱图和地图高度。聚焦横线后也可按 ↑、↓。调整值与「设置 → 偏好 → 控件参数」同步，刷新后保留。
- 桌面版可在「设置 → 偏好 → 界面字号」选择 12–18 px 的字号。改动立即生效，刷新后保留。

**设置 → 偏好 → 事件计数方式**中的三项默认开启，可单独关闭。

- **同日去重**让同一天重复出现的地点和同伴各计一次。类型排行和地图次数也使用相同的日期口径。
- **跨天行程按天计**让「之旅」中的同伴按行程天数计，地点按备注中明确记录的日期计。同一地点跨天可多次计数，日期待确认的地点仅在行程开始日计一次。
- **按周期展开事件**展开范围内的重复记录，处理排除日期和单次改期。

前两项影响排行、地图次数和回顾中的到访统计。事件列表、时间足迹的事件量和年度回顾的事件总数仍按日程事件计算。

偏好底部的 **应用版本** 显示提交号和提交时间，精确到分钟。点击提交号可在 GitHub 查看对应提交。工作区尚未提交的改动仍显示当前提交号。

## 行程

工具栏的 **旅游行程** 汇集标题含「之旅」的事件。也可以从事件列表点行程图标，直接打开对应行程。多日行程的备注可用 `【4/5】`、`4月5日`、`Day 2` 或类似标题分天，每天的 `Place：` 按原文顺序列出。列表可以滚动，点击日期可收起当天的地点。

多日行程默认显示 **总览**，地图数字从行程开始日算起，颜色区分日期，「?」表示日期待确认。单日行程直接显示当天。查看单个日期时，地图数字表示当天的地点顺序。地图右上角的 **图层 → 连线** 按当天已定位地点的顺序画线。

在「设置 → 偏好 → 控件参数 → 行程底图」选择行程和行程分享图使用的在线底图。

未定位的地点以浅色显示。点击已定位的地点可隐藏或恢复该地点在地图上的点位，同一行程的总览和分日共用这项选择，关闭行程窗口后恢复。隐藏的地点也会从分享图的地点清单、点位和路线移除。

点 **关闭** 左侧的 **导出** 可预览并下载当前总览或单日的 PNG。可以选取地点、地图、连线和同伴，同伴默认隐藏。地图需要开启地点，连线还需要开启地图。下载使用预览中的图像，地图署名随底图变化。底图无法加载时，预览和下载的图像均保留点位。

## 年度回顾与跨年统计

1. 打开 **年度回顾** 时默认显示最新有记录的年份，可用左右按钮或下拉菜单换年。下拉第一项 **跨年统计** 可自选起止日期，起止当天都计入。
2. 全国足迹左下角可开关南海诸岛。勾选「聚焦到访」后按点亮城市取景，并暂停南海诸岛开关。到访多个国家或地区时，标题会显示数量。窄屏会放大城市名称，并将上海的全市图与中心城区图上下排列。全市图可开关崇明区，中心城区图可用「内环」缩放。悬停或轻点上海地图上的点位可查看附近的地点。上海图用主题对比色标出常去地点 Top 5 中位于上海的地点。
3. 年度回顾可点击地铁费用数字或「—」编辑，点击别处保存到当前浏览器。跨年统计显示范围内的事件、记录天数、到访地点和同伴，同名月份汇总到一根柱子。
4. 点 **导出**直接下载当前回顾的 PNG。地图范围与页面预览一致。

## 手机导入与更新

在 iPhone 上，用 Safari 打开 [日历足迹网页版](https://myronxie.github.io/calendar-atlas/)，从分享菜单选择 **添加到主屏幕**。如果出现 **作为网页 App 打开**，打开该选项。首次从主屏幕进入后再导入数据。已缓存的页面和图层可离线使用，在线底图及未缓存的图层需要联网。

手机缺少文件时，打开应用会弹出导入框。把 `atlas-data/` 中的 `calendar.ics`、`place.csv`、`config.json` 原样传到手机，按提示选择缺少的文件。之后可在 **偏好**、**地点管理**或 **排除设置**中点击对应文件旁的 **+** 来替换文件。行内时间记录本次导入或替换的时间。

手机导入的数据保存在当前网站或应用的 IndexedDB，取决于浏览器或安装后的网页 App 的存储；换设备或清除数据后可重新导入这三个文件。

## 日历备注格式

```text
Partner：甲；乙
Place：地点一；地点二
安排：上午游览，另有几位朋友参加
```

人物与地点在各自的行填写。备注正文只提取 `Partner` 和 `Place`，另保留 ICS 的 `LOCATION` 主地点。多个地点或同伴优先使用分号，带空格的英文地点可用引号括起。分店名称的紧连括号保留。标题可用 `[组别]事件名称`，页面会分别提取组别和事件名。

## 常见问题

- 页面打不开时，先确认启动入口成功、Node.js 可用且本机 8787 端口可用。
- 底图加载失败时可切换提供商，本地行政区地图和上海地铁底图也可使用。在线底图会把瓦片请求的视野位置发给地图提供商。OpenTopoMap 适合看地形，查看街区时可选街道底图。
- CSV 用 UTF-8 打开并保留逗号分隔及表头。补坐标清单可人工合并回主库。
- 「设置 → 偏好」的配色方案旁可切换夜间模式，当前配色仍可独立选择。在线瓦片保持原样，行程和年度回顾分享图使用浅色纸面。配色、夜间模式、字号、排行设置、回顾地图开关和地铁费用保存在当前浏览器。换电脑或浏览器时，文件备份可以恢复日历、地点和配置，浏览器偏好需另外迁移。

项目 ZIP 的备份与恢复步骤见 [维护与备份](维护与备份.md)。
