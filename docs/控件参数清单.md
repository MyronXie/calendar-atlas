# 日历足迹 · 前端控件参数清单

> 用途：逐个区域审阅界面控件的尺寸、颜色、间距与响应式差异。
> 依据：`style.css`（令牌与规则）、`index.html`（静态结构）、`app.js`（动态生成控件）、`lib/appearance.js`（主题色）。
> 说明：文中尺寸单位均为 CSS px；「移动端」默认指 `max-width:650px`，其余条件单独注明。颜色令牌见第 1 节，控件表中用 `token` 表示。

## 1. 全局设计令牌（Design Tokens）

### 1.1 字体与字号

| 令牌 | 值 | 说明 |

## 2. 响应式断点总览

| 条件 | 影响的区域与变化 |
| --- | --- |
| 容器 `home ≥1100px` | 时间/事件变**双栏**：各栏最小 440px，中间分割条 6px，栏间距 14px；右栏事件独立滚动 |
| 容器 `events ≤590px` | 事件行改为「时间列 + 内容列」两列布局；地点/人物按钮变图标、隐藏文字 |
| 容器 `timeline ≤350px` | 时间范围标题缩字号并允许换行 |
| 容器 `timeline-body ≤475px` | 时间统计从 4 列变 2 列 |
| `max-width:1280px` | 排行/设置抽屉互斥（打开一个会收起另一个） |
| `max-width:1100px` | 抽屉宽 330/内边距 12；地图高度改为 `max(200px,40vh)`；地图工具 gap5、select 最大 130px |
| `max-width:650px` | 移动端：抽屉变覆盖层（宽 `min(84vw,360px)`），关闭键移到抽屉外侧；主标题栏收紧、隐藏应用名、显示「行程/回顾」短标签；面板外边距 8、内边距 9/12；单位切换圆角 6；日期字号 16；地图高度 `max(170px,32vh)` |
| `max-width:480px` | 年度回顾字号/统计格/图例缩小 |
| `max-width:360px` | 主题选项按钮与色块间距、十六进制字号缩小；抽屉标签字号 12、间距 2 |
| `max-width:330px` | 抽屉标签字号 11、左右内边距 0（极窄屏防溢出） |
| `max-width:350px` | 日期字段改单列；标题栏按钮左右间距 4 |
| `max-height:760px` | 地图高度按 `max(200px,40vh)` |
| `(max-width:650px) or (max-height:540px)` | 行程对话框改为全高、可滚动日期标签 |
| `max-height:540px` | 主标题栏**不吸顶**；行程/回顾简写；应用名隐藏；按打开的抽屉隐藏排行或设置之一文字；单位切换圆角 6 |
| `prefers-reduced-motion` | 抽屉/主区过渡取消 |
