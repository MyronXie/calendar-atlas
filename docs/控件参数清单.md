# 界面和样式约定

`style.css` 是尺寸及布局参数的来源，`lib/appearance.js` 定义颜色，`index.html` 管理线绘图标。

| 项目 | 约定 |
| --- | --- |
| 字号与间距 | 默认正文 15px，标题为正文 +3px。控件字号为正文减 1px，说明文字减 2px。间距使用 4、8、12、16px |
| 控件尺寸 | 常规 36px，密集列表控件 32px。当前、重置、地点、人物复用宽度，图标态 36px。抽屉标签与工具栏同字号，汇总复选框小一号 |
| 主题 | `canvas` 用于画布，`surface` 用于面板，`line` 用于分隔；`accent` 用于主操作、选中和点位，前景由对比度决定 |
| 筛选颜色 | 日期拖选用 `soft`，当天事件命中用 `mid`。地点、人物、活动等匹配用 `highlight` 派生的颜色 |
| 地图与排行 | 单点用高对比线绘、聚合用数字圆标；上海普通点、地标、聚合依次叠高。前三名名次按钮用主题色底，计数统一右对齐 |
| 浮层 | 鼠标提示和触屏计数提示共用表面色、描边和字号。手势语义见[操作对照](使用说明.md#桌面与触屏操作对照) |

## 响应式

- 双栏各保留至少 440px；回到单栏清除上次拖动宽度。窄事件栏把事件、地点、人物和命中备注依次排在时刻旁。
- 时间栏根据日期旁的实际剩余宽度先隐藏操作文字，再简写「总／筛」，最后缩窄时间单位。需要时换行。
- 窄窗口使用覆盖式抽屉，关闭按钮放在抽屉外侧。矮屏工具栏随页面滚动。时间和地图面板底部手柄与偏好中的高度设置同步。
- 修改界面时同时看宽窄布局和日夜主题。组件优先复用现有控件尺寸和主题变量。
